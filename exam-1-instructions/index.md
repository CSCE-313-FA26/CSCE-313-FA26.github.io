## 1. Description

Exam 1 is a **coding exam**, with some written questions. It works the same way
as the in-class activities:

1. Accept the exam repository.
2. Clone it.
3. Do the work.
4. Commit and push, as usual.

It is a **take-home** exam. **There is no class on Thursday, October 15.**

## 2. Date, Time and Duration

| | |
| --- | --- |
| **Date** | Thursday, October 15, 2026 |
| **Window** | 9:00 AM – 11:59 PM CT |
| **Duration** | 2 hours |

You choose when to start. The exam window opens at 9:00 AM, and you have
**2 hours** from whenever you begin.

**Nothing pushed after 11:59 PM CT is accepted.** Two hours before that is
9:59 PM, so **9:59 PM is the latest you can start** and still have your full time.

Commit and push as you go rather than all at the end. A push that fails at
11:58 PM is not a submission.

## 4. Technical Requirements

**Make sure your Linux environment works.** Do this well before October 15 — an
environment problem discovered at the start of your two hours comes out of your
two hours.

Check each of these on the machine you will actually use:

- You can **clone** one of your lab or activity repositories.
- It **builds** with `make` and the program **runs**.
- You can **commit and push** a change, and see it on GitHub.
- The **Honorlock** setup you use for in-class activities launches from Canvas.

## 5. Exam Preparation

- Study the in-class examples and activities.
- Read the suggested textbook chapters.
- Study the labs.

## 6. Topics

These are topics that **may** be included in Exam 1. The list is **not
exhaustive** — it is here to help you review.

- Process API
- Process attributes
- Concurrent processing
- Context switching
- Linux pipes and FIFOs
- `fork()` and `exec()` system calls
- Process synchronization using `wait()` and `waitpid()`
- UNIX file I/O and file descriptors
- File systems
- UNIX signals\*

\* Coverage up to exam day.

## 7. Testing Accommodations

**There is no separate exam date to schedule.** Students with approved testing
accommodations take the exam on the **same date as everyone else — Thursday,
October 15, 2026.**

There is **no lecture on October 15** specifically so that you can take the exam
remotely, in the setting that works best for you — at the testing center, or at
any location you choose.

- **No in-person proctor is required.** The exam must still be completed under
  **Honorlock through Canvas**, the same as for every other student.
- **Apply your approved extended time yourself.** The exam will not lock you out
  when the standard two hours are up. GitHub records the time of every push.
- **The 11:59 PM CT deadline applies to you as well. Nothing pushed after
  11:59 PM CT is accepted, including extended time.** Plan your start time so
  that your full extended time ends by 11:59 PM:

| Approved time | Your duration | Latest start |
| --- | --- | --- |
| Standard | 2 hours | 9:59 PM CT |
| 1.5× | 3 hours | 8:59 PM CT |
| 2× | 4 hours | 7:59 PM CT |

If anything about your accommodations is unclear, contact the instructor before
exam day.
